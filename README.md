# RentShield (MVP in progress)

RentShield helps renters upload a rent statement or move-out statement, understand charges, and generate a dispute email.

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`
